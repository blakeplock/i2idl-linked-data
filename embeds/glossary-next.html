How this glossary works

A human-readable glossary built on an interoperable semantic model.

The glossary operates as an explicitly connected knowledge graph. Every concept participates in collections and internal semantic relationships. External mappings connect selected concepts to authoritative vocabularies such as UNESCO Thesaurus and Schema.org.

The I2IDL Glossary of Digital Learning is designed to serve both people and machines. Readers can search, browse, filter, and explore concepts through the public glossary, while the same content is maintained underneath as structured semantic data.

Each concept has a stable identity. Definitions, source evidence, classifications, relationships, provenance, citation details, and licensing information are maintained as connected parts of the record rather than as isolated text entries.

The glossary uses JSON-LD together with established standards including SKOS, Schema.org, Dublin Core Terms, and PROV-O. This allows the same underlying content to support linked data, terminology systems, publishing workflows, semantic applications, research tools, AI-assisted discovery, and web services.

Fields and types are used as editorial groupings, while semantic relationships can connect concepts across the glossary without forcing them into a single hierarchy. Definitions retain their own provenance and source relationships so the basis for each entry remains traceable.

The public glossary is one presentation of this underlying model. Its search, filtering, navigation, source links, and concept cards are generated from the same structured data that supports the machine-readable services.

Linked Data: The complete glossary is available in machine-readable JSON-LD at https://id.i2idl.org/glossary.jsonld.

Stable identifiers: Concepts, definitions, sources, and the glossary concept scheme are published under the persistent namespace https://id.i2idl.org/.

REST API: A public, read-only REST API provides structured access to glossary concepts and their semantic context for integration with applications, research systems, and other services. API reference documentation and an OpenAPI specification are available through the Developer Portal.

Model Context Protocol (MCP): A public MCP server enables compatible AI assistants and applications to search glossary concepts, retrieve definitions and semantic context, and explore relationships using the curated knowledge graph. The service is read-only and does not permit AI systems to modify glossary content. Connection instructions are available in the MCP Quick Start Guide.

SPARQL: The glossary can also be queried directly through a read-only SPARQL endpoint at https://id.i2idl.org/sparql.

Knowledge Graph Explorer: Browse semantic relationships, investigate shortest paths, compare concepts, and discover related scholarly literature through the I2IDL Graph Explorer. Each glossary concept also links directly to its graph view.

Developer resources: API documentation, integration guidance, and access to the glossary's machine-readable services are available through the I2IDL Developer Portal.
