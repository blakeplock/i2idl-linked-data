Identifiant internationalisé de ressource (IRI)

Définition

Format d’identifiant globalement unique utilisé dans xAPI pour identifier verbes, activités, types d’activités, extensions et concepts de vocabulaire ; les IRI peuvent contenir des caractères internationaux et comprennent un schéma.

IRIs let independent systems refer to the same concepts without relying on local database identifiers, which is fundamental to semantic interoperability.
