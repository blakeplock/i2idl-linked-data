Learning Engineering / Method

Modèle SAMR

Définition

Cadre décrivant quatre niveaux d’utilisation des technologies dans l’apprentissage : substitution, augmentation, modification et redéfinition.

Explication éditoriale

L’explication éditoriale suivante est actuellement disponible en anglais.

SAMR helps designers distinguish between using technology to reproduce old tasks and using it to enable forms of learning that were previously difficult or impossible.
