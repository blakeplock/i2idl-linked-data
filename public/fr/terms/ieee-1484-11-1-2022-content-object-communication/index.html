IEEE 1484.11.1-2022 — Data Model for Content Object Communication

Définition

Norme IEEE définissant le modèle de données pour échanger des renseignements sur apprenant, interactions, objectifs, statut, temps, préférences et résultats entre un objet de contenu pédagogique et un service d’exécution, généralement au sein d’un LMS.

Explication éditoriale

L’explication éditoriale suivante est actuellement disponible en anglais.

The standard provides a common runtime data model for LMS-delivered content and forms part of the technical foundation associated with SCORM-style content-to-platform communication.
