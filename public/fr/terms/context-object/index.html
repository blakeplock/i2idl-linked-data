Objet de contexte

Définition

Composant facultatif d’une déclaration xAPI ajoutant des renseignements contextuels sur une expérience, tels que l’inscription, les activités associées, les agents ou groupes pertinents, la langue, la plateforme, une autre déclaration ou des extensions.
