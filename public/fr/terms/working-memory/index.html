Learning Sciences / Concept

Mémoire de travail

Définition

Système de mémoire à capacité limitée dans lequel l’information est traitée consciemment avant une éventuelle consolidation dans la mémoire à long terme.

Because working memory is limited, excessive new information or unnecessary complexity can overwhelm learners and interfere with understanding.
