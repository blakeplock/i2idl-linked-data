Human-Centered Design / Practice

Personnalisation pilotée par l’utilisateur

Définition

Possibilité pour les utilisateurs d’adapter le comportement ou la configuration d’une technologie d’apprentissage selon leurs besoins, expérience, contexte ou niveau de soutien souhaité.

Customization can make a system useful across diverse learners and practitioners without assuming that one configuration or level of guidance will work for everyone.
