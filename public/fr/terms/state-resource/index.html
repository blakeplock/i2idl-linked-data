State Resource

Définition

Ressource xAPI située à /activities/state pour stocker et récupérer des documents d’état associés à un agent ou groupe identifié dans une activité, éventuellement liés à une inscription.

The State Resource gives learning applications a standards-based place to persist activity state across devices or sessions without defining a new storage API.
