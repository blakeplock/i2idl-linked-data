Cycle des données éducatives

Définition

Séquence récurrente où les données éducatives sont produites et rendues disponibles, communiquées et partagées, analysées puis utilisées pour éclairer les décisions et les besoins ultérieurs en données.

Explication éditoriale

L’explication éditoriale suivante est actuellement disponible en anglais.

The cycle emphasizes that collecting data is only one stage of an effective data system; value emerges when data moves through reporting, analysis, and use.

  • Prise de décision fondée sur des données probantes
  • Prise de décision éclairée par les données
  • Utilisation des données
