IEEE 9274.1.1-2023 — Experience API (xAPI)

Définition

Norme IEEE définissant le modèle de données xAPI et le service web REST permettant de communiquer les données d’expériences d’apprentissage et de performance humaine entre activités et Learning Record Store (LRS), selon un modèle JSON et des comportements dérivés de xAPI 1.0.3.
