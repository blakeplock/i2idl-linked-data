Learning Engineering / Practice

Amélioration continue

Définition

Pratique permanente consistant à utiliser les données probantes et la rétroaction pour perfectionner progressivement les expériences, systèmes, processus et opérations d’apprentissage.

Explication éditoriale

L’explication éditoriale suivante est actuellement disponible en anglais.

Learning conditions change, so effective systems need mechanisms for learning from use rather than assuming the first release is final.
