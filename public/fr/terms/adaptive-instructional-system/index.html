Learning Engineering / System

Système pédagogique adaptatif

Définition

Système d’apprentissage qui modifie les contenus, leur séquencement, le soutien apporté, la rétroaction ou le niveau de difficulté en fonction d’informations concernant un apprenant ou le contexte.
