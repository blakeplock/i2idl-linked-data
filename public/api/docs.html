Glossary REST API

Search and navigate the I2IDL Glossary of Digital Learning with simple JSON requests. API v1 is read-only, public, and backed by the canonical Linked Data publication.

API contract v1 and glossary publication versions are independent. OpenAPI 3.1 specification · Canonical JSON-LD · SPARQL

Use it in your application

JavaScript
const response = await fetch(
  'https://id.i2idl.org/api/v1/concepts?q=learning'
);
if (!response.ok) throw new Error('API error');
const data = await response.json();
console.log(data.items);
Python
import requests

response = requests.get(
    'https://id.i2idl.org/api/v1/concepts',
    params={'q': 'learning'},
    timeout=15,
)
response.raise_for_status()
print(response.json()['items'])
cURL
curl --get \
  'https://id.i2idl.org/api/v1/concepts' \
  --data-urlencode 'q=learning'
Semantic identifiers

Each concept retains its permanent URI. Use the JSON-LD and Turtle links in concept responses when you need RDF, and the historical versions endpoint for immutable revision metadata.
