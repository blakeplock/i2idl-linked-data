I2IDL Digital Learning Glossary - Linked Data

This service publishes the I2IDL Digital Learning Glossary as interoperable Linked Data.

Concepts use stable HTTPS identifiers and are represented with JSON-LD using SKOS, Schema.org, Dublin Core Terms, PROV-O, and the I2IDL/Glossary Studio application profile.
