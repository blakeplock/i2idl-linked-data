JSON-LD

Definition

A JSON-based linked-data format that maps familiar JSON structures to semantic identifiers and relationships that can be interpreted as RDF.

Editorial explanation

xAPI Profiles use JSON-LD so Profile documents remain approachable as JSON while also participating in linked-data and RDF tooling.
