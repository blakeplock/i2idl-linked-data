Assessment & Measurement / Concept

Result Object

Definition

The optional xAPI Statement component used to represent a measured outcome, including values such as score, success, completion, response, duration, and extensions.

Editorial explanation

Result data lets a Statement represent more than the fact that an event occurred by carrying evidence about how the experience turned out.
