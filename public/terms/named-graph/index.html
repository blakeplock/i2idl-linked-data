Standards & Interoperability / Concept

Named graph

Definition

In the xAPI Profile Server model, the RDF graph used to store a particular Profile version under that version’s URI so the version can be queried directly.

Editorial explanation

Profile Servers use named graphs to preserve and directly query individual historical Profile versions while keeping current versions available in the default graph.
