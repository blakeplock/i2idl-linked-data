Attachment

Definition

A file or other binary resource logically associated with an xAPI Statement, described by metadata including usage type, display name, content type, length, SHA-2 hash, and optionally a file URL.

Editorial explanation

Attachments allow evidence such as certificates, essays, images, or other artifacts to travel with or be referenced from a Learning Record while preserving integrity checks.
