Agent Profile Resource

Definition

The xAPI resource at /agents/profile for storing and retrieving generic profile documents associated with an Agent or Identified Group, independent of a specific Activity or registration.

Editorial explanation

Agent Profile documents can hold information needed by applications without forcing that information into Statements or activity-specific state.
