Data security

Definition

The practices and controls used to protect learning data, systems, interfaces, storage, and communications from unauthorized access, manipulation, loss, or disruption.

Editorial explanation

Connected learning ecosystems increase the amount and mobility of learner data, making security a system-wide design and governance requirement.
