Profile server

Definition

A centralized service for finding, browsing, querying, storing, and managing xAPI Profiles, vocabulary concepts, and related Profile metadata.

Editorial explanation

A Profile Server makes Profiles discoverable and queryable and provides infrastructure for working with current and historical Profile versions.
