xAPI concurrency control

Definition

The xAPI use of HTTP entity tags and conditional request headers to prevent State, Agent Profile, or Activity Profile updates and deletes from being based on stale data.

Editorial explanation

Concurrency control protects shared document resources from accidental overwrites when multiple clients read and modify the same data.
