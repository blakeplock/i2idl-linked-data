xAPI Profile

Definition

Human- and/or machine-readable documentation of application-specific Concepts, Statement Templates, Patterns, and extensions used when implementing xAPI in a particular context.

Editorial explanation

Profiles improve semantic interoperability by helping independent systems use the same concepts and statement patterns consistently.
