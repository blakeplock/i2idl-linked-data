Assessment & Measurement / Standard

Interaction Activity

Definition

An xAPI Activity Definition used to describe an interaction such as true-false, choice, fill-in, matching, performance, sequencing, Likert, numeric, or other response formats.

Editorial explanation

Interaction Activities give assessment and practice events a structured representation that can preserve response semantics across systems.
