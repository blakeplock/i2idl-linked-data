Document Profile Resource

Definition

An xAPI construct for storing document-style information about an Agent or Activity in name-and-document pairs meaningful to an instructional system component. It is distinct from an xAPI Profile.

Editorial explanation

The distinction prevents confusion between profile documents used as storage and xAPI Profiles used to constrain vocabularies, templates, and patterns.
