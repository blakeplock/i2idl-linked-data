State Resource

Definition

The xAPI resource at /activities/state used to store and retrieve arbitrary state documents associated with an Agent or Identified Group in an Activity, optionally tied to a registration.

Editorial explanation

The State Resource gives learning applications a standards-based place to persist activity state across devices or sessions without defining a new storage API.
