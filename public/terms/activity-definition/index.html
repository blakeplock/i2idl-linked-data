Activity Definition

Definition

The optional metadata object within an xAPI Activity that can describe its human-readable name, description, type, more-information location, interaction details, and extensions.

Editorial explanation

Activity Definitions add understandable metadata to stable Activity identifiers without making that metadata the identifier itself.
