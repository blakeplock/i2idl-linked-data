xAPI timestamp

Definition

The time at which the event described by a Statement occurred, represented using the timestamp rules defined by xAPI, including ISO 8601 and RFC 3339 formatting.

Editorial explanation

Separating event time from storage time makes it possible to capture offline or delayed reporting while preserving when the experience actually happened.
