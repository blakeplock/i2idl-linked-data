Learning Engineering / Practice

Reflective design documentation

Definition

Documentation used during design to externalize decisions, reasoning, and context so practitioners can reflect on and revisit the work as it develops.

Editorial explanation

Reflection becomes more actionable when the reasoning behind choices is recorded close to the work itself rather than reconstructed later from memory.
