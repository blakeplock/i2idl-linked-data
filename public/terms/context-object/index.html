Context Object

Definition

The optional xAPI Statement component used to add surrounding information about an experience, such as registration, related activities, relevant Agents or Groups, language, platform, another Statement, or extensions.

Editorial explanation

Context lets the same core Actor-Verb-Object event be interpreted within a broader learning, organizational, technical, or situational setting.
