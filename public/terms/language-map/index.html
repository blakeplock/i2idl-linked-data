Language Map

Definition

An xAPI dictionary whose keys are RFC 5646 language tags and whose values are strings in the corresponding languages.

Continue exploring

Explore related concepts, research, and semantic relationships in the full I2IDL Glossary of Digital Learning.

Editorial explanation

Language Maps let the same xAPI concept carry human-readable labels or descriptions in multiple languages while preserving a shared machine-readable identifier.
