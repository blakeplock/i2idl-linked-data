IEEE 9274.1.1-2023 — Experience API (xAPI)

Definition

The IEEE standard for the xAPI data model and RESTful web service used to communicate learner and human-performance experience data between activities and a Learning Record Store (LRS). It standardizes the JSON-based model and service behavior derived from xAPI 1.0.3.

Editorial explanation

xAPI provides a common way for heterogeneous learning, performance, simulation, mobile, and other systems to record and exchange experience data outside the boundaries of a single LMS.
