Internationalized Resource Locator (IRL)

Definition

In the xAPI standard, an IRL is an IRI that can be translated to a URI that functions as a URL.

Editorial explanation

xAPI distinguishes identifiers from locators because some identifiers merely name concepts while others can also be used to retrieve resources or metadata.
