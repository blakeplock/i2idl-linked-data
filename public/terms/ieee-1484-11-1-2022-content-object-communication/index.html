IEEE 1484.11.1-2022 — Data Model for Content Object Communication

Definition

An IEEE standard defining the data model used to exchange learner, interaction, objective, status, timing, preference, and score information between a learning content object and a runtime service, typically within an LMS environment.

Editorial explanation

The standard provides a common runtime data model for LMS-delivered content and forms part of the technical foundation associated with SCORM-style content-to-platform communication.
