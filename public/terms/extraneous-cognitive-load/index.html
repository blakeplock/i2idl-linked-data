Learning Sciences / Concept

Extraneous cognitive load

Definition

Mental effort caused by features of a task or presentation that do not directly support the learning goal.

Editorial explanation

Reducing unnecessary complexity can preserve cognitive resources for understanding, practice, and problem solving.
