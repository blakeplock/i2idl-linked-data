Formative evaluation

Definition

Evaluation primarily intended to provide feedback that can be used to improve teaching, management, implementation, or school effectiveness.

Editorial explanation

Formative evaluation distinguishes improvement-oriented uses of evaluation from summative uses focused on judgement, outcomes, or accountability.
