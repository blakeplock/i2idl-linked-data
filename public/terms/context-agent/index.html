Context Agent

Definition

An xAPI context structure that represents a Statement-specific relationship between the Statement and a relevant Agent, optionally characterized by one or more relationship-type IRIs.

Editorial explanation

Context Agents allow people who influenced or participated in an experience to be represented without incorrectly making them the primary Actor.
