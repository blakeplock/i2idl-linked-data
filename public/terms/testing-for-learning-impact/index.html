Assessment & Measurement / Method

Testing for learning impact

Definition

Evaluation that examines whether a solution changes learning, retention, transfer, performance, or other intended outcomes rather than only usability or satisfaction.

Editorial explanation

A learning product can be easy to use and still fail to improve learning, so impact requires its own evidence.
