Learning Engineering / Practice

Flipped classroom

Definition

An instructional approach that moves direct content delivery outside class time and uses shared face-to-face time for more interactive learning activities.

Editorial explanation

The flipped classroom shows how digital delivery can change the purpose of classroom time rather than simply digitizing traditional lectures.
