Learning Sciences / Concept

Working memory

Definition

The limited-capacity memory system in which information is consciously processed before it may be encoded into long-term memory.

Editorial explanation

Because working memory is limited, excessive new information or unnecessary complexity can overwhelm learners and interfere with understanding.
