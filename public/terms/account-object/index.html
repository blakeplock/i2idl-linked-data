Account Object

Definition

An xAPI identity structure that represents an Agent or Group through an account on an existing system using a home page for the account system and a unique account name.

Editorial explanation

Account Objects provide a way to identify Actors when an email address or OpenID is not appropriate, while keeping the identity tied to a known account namespace.
