Metadata Consumer

Definition

A person, organization, software program, or other entity that determines the meaning represented by an IRI or retrieves metadata about that IRI.

Editorial explanation

Metadata consumers allow identifiers to carry reusable semantics beyond a single Statement, supporting discovery, interpretation, and shared vocabularies.
