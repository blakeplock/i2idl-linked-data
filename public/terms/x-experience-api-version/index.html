X-Experience-API-Version

Definition

The HTTP header used in xAPI requests and responses to declare the xAPI version being used.

Continue exploring

Explore related concepts, research, and semantic relationships in the full I2IDL Glossary of Digital Learning.

Editorial explanation

Explicit version negotiation helps clients and LRSs remain interoperable as the specification changes and prevents silent assumptions about incompatible versions.
