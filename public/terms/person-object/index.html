Person Object

Definition

An xAPI response object that combines known identifying information about an Agent into arrays of values, providing a person-centric view of Agent data while remaining distinct from an Agent persona.

Editorial explanation

The Person Object helps an LRS return related Agent identity information without pretending that every representation of a person is a single Agent record.
