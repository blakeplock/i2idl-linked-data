IEEE 1484.13.6-2015 — OAI-ORE Resource Aggregation Mapping

Definition

An IEEE recommended practice mapping the Open Archives Initiative Object Reuse and Exchange (OAI-ORE) Abstract Model and its RDF/XML resource-map representation to the IEEE conceptual model for resource aggregation.

Editorial explanation

It bridges a web-oriented resource aggregation model with the learning-technology resource model, helping preserve meaning when aggregated resources move across technical ecosystems.
