Learning Engineering / Practice

Continuous improvement

Definition

An ongoing practice of using evidence and feedback to refine learning experiences, systems, processes, and operations over time.

Editorial explanation

Learning conditions change, so effective systems need mechanisms for learning from use rather than assuming the first release is final.
