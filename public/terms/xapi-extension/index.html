xAPI extension

Definition

A custom property expressed in an xAPI extensions map using an IRI as the key and any JSON value or structure as the value. Extensions can appear in Activity Definitions, Statement Context, or Statement Result.

Editorial explanation

Extensions give communities room to represent domain-specific information while keeping the core Statement model stable; interoperability is strongest when built-in properties are used whenever possible.
