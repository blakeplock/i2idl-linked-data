IEEE 1484.11.2-2020 — ECMAScript API for Content-to-Runtime Communication

Definition

An IEEE standard defining an ECMAScript application programming interface for communication between learning content and a runtime service, typically supplied by a Learning Management System. It standardizes common API services used to exchange runtime learning data.

Editorial explanation

The API gives browser-based learning content and LMS runtime services a common communication contract and reduces ambiguity in content-to-platform integration.
