Learning Engineering / System

Virtual classroom

Definition

A multi-person learning environment created in software and supported by networked computer-mediated communication rather than a shared physical room.

Editorial explanation

The virtual classroom helped establish the idea that teaching and learning communities could persist across distance through networked technologies.
