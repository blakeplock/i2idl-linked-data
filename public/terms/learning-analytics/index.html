Learning Analytics / Discipline

Learning analytics

Definition

The analysis and use of data from learning environments to understand and improve learning experiences, instructional strategies, and related decisions.

Editorial explanation

Learning analytics converts event data into evidence, but its value depends on instrumentation, measurement validity, interpretation, and responsible use.
