Resource Description Framework (RDF)

Definition

A semantic data model that represents information as subject–predicate–object relationships, allowing identifiers and relationships to be combined across datasets.

Editorial explanation

The Profiles specification uses RDF as the semantic model behind Profile data, and Profile Servers store and query Profiles as RDF.
