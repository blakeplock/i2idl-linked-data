Data & Instrumentation / Concept

xAPI document

Definition

Document data stored through the xAPI State, Agent Profile, or Activity Profile Resources. These resources store state or profile information in a generic document form scoped to an Activity, Agent or Identified Group, and, for State, optionally a registration.

Editorial explanation

Documents let xAPI applications persist state and profile information outside immutable Statements while keeping that information associated with the relevant Activity, Agent, Group, or registration.
