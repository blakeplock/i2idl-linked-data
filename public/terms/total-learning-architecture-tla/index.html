Total Learning Architecture (TLA)

Definition

A standards-based approach to interoperable learning ecosystems that connects learning activity data, learner information, competencies, analytics, and other services across systems.

Editorial explanation

The TLA provides an architectural context for using learning data standards as parts of a broader ecosystem rather than as isolated specifications.
