Learning Engineering / Practice

Investigation phase

Definition

The part of the learning engineering process in which collected data are analyzed to explore outcomes and determine how well a solution addresses the learning challenge.

Editorial explanation

Investigation turns implementation data into evidence for deciding whether to refine the design, continue implementation, or reframe the problem itself.
