Learning Record Store (LRS)

Definition

A system that receives, stores, and provides access to xAPI learning records.

Continue exploring

Explore related concepts, research, and semantic relationships in the full I2IDL Glossary of Digital Learning.

Open this concept in the glossary →

Editorial explanation

An LRS is a core component in architectures where learning event data must be collected independently of any single delivery platform.
