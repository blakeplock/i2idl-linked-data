IEEE 2881-2025 — Learning Metadata Terms

Definition

An IEEE learning technology standard that defines an extensible set of metadata classes and properties for describing learning resources and learning events. Its model is designed to align with Resource Description Framework (RDF) approaches and can be represented in graph-oriented and other formats.

Editorial explanation

Shared metadata terms make learning resources and events easier to describe, discover, exchange, connect, and reuse across systems without forcing every platform to invent its own vocabulary.
