Statement Result

Definition

The response structure returned when an LRS query retrieves multiple Statements, containing the returned Statements and, when more results are available, a link for retrieving the next set.

Editorial explanation

Statement Results support paging and controlled retrieval of large bodies of xAPI data instead of requiring every matching Statement to be returned at once.
