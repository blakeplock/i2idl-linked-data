Signed Statement

Definition

An xAPI Statement that includes a JSON Web Signature as an Attachment so that the authenticity and integrity of the original Statement serialization can be verified.

Editorial explanation

Signing provides stronger evidence that a record came from the claimed source and has not been altered, which can matter in higher-trust learning and credentialing contexts.
